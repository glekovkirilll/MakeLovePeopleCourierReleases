# MakeLovePeopleCourierReleases

Публичные Android-релизы приложения `MakeLovePeople.Курьер`.

Исходный код приложения хранится в приватном репозитории. Здесь публикуются только:
- готовые APK-файлы
- заметки к релизам
- краткая инструкция по установке

## Скачать

Актуальные версии лежат на вкладке `Releases`:

<https://github.com/glekovkirilll/MakeLovePeopleCourierReleases/releases>

## Установка на Android

1. Скачайте `.apk` из нужного релиза.
2. Откройте файл на телефоне.
3. Если Android спросит разрешение на установку из браузера или файлового менеджера, разрешите его.
4. Установите приложение.
